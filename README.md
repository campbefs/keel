# keel

Source for [keel.dev's site](https://campbefs.github.io/keel/) — Keel builds Shopify apps.

**[Giftline](https://apps.shopify.com/keel-giftline)** adds a free gift to the cart when a shopper
reaches your threshold, and takes it back out if the cart drops below.

Built with Jekyll on GitHub Pages. Questions: campbefs@gmail.com
